
# Java Console Based Projects

This repository contains Java console-based applications developed using Core Java concepts and Object-Oriented Programming (OOP).

 📌 Projects Included
 1. Banking Management System
Features:
- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- Display All Accounts

2. Theater Ticket Booking System
Features:
- Book Tickets
- Cancel Tickets
- Display Seat Availability

3. Inventory Management System
Features:
- Add Product
- Search Product
- Update Quantity
- Delete Product
- Display Products

🛠 Technologies Used
- Java
- OOPs Concepts
- ArrayList
- Scanner Class
- CRUD Operations
